# SerOAI

Android-приложение-чат с **Gemma 4 E2B-it**, которое работает **полностью на телефоне** через Google LiteRT-LM.
Тёмная фиолетовая тема, минималистичный интерфейс, плавные анимации.

Модель: https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm (файл `gemma-4-E2B-it.litertlm`, ~2.6 ГБ).
Приложение само скачает её при первом запуске. API-ключи не нужны.

## Возможности
- Потоковые ответы (текст появляется по мере генерации), кнопка «Стоп»
- Markdown: заголовки, списки, **жирный**, `код`, блоки кода с кнопкой «Копировать»
- Фото в сообщениях (Gemma 4 понимает изображения)
- Много чатов: история, переименование, удаление, автосохранение
- «Ещё раз» (перегенерация), копирование ответов, долгий тап по своему сообщению — копировать
- Настройки: GPU/CPU, режим размышления, температура, Top-K, Top-P, системный промпт
- Загрузка модели с докачкой, скоростью и оставшимся временем, или импорт готового `.litertlm`
- Автоматический переход на CPU, если GPU не поддерживается

## Как получить APK без компьютера с Android Studio (GitHub Actions)
1. Создайте пустой репозиторий на github.com.
2. Загрузите туда **содержимое** этой папки (Add file → Upload files; папку `.github` тоже).
   Или из терминала: `git init && git add . && git commit -m init && git branch -M main && git remote add origin <URL> && git push -u origin main`.
3. Откройте вкладку **Actions** → сборка запустится сама (~5–8 минут).
4. Откройте завершённую сборку → внизу **Artifacts → GemmaViolet-apk** → скачайте zip, внутри `GemmaViolet.apk`.
5. Скиньте APK на телефон и установите (разрешите «установку из неизвестных источников»).

## Сборка в Android Studio
Откройте папку проекта → дождитесь синхронизации Gradle → Build → Build APK(s).

## Требования
- Android 8.0+ (arm64), лучше 6+ ГБ ОЗУ
- ~3 ГБ свободного места

## Структура
- `llm/LlmEngine.kt` — работа с LiteRT-LM (загрузка, диалог, потоковая генерация)
- `data/ModelDownloader.kt` — скачивание модели с Hugging Face с докачкой
- `ui/` — экраны на Jetpack Compose (настройка, загрузка, чат, настройки)
